How it works

1. diff: git diff base...head, parsed into files, hunks and line numbers.
2. RAG: the whole repo at the head (docs + code) indexed; a query per hunk; rules from docs/conventions.md pinned.
3. MCP: the model can read_file etc. on the PR's head.
4. LLM: JSON findings: bugs, architecture, recommendations.
5. check: a finding must point into the diff.
The GitHub Action posts the same review as a PR comment. This page never posts.
